# Dustins Blog

This was my first major step into web development, built to serve as a platform for my personal blog, photography, and sermon audio. What started as a learning project evolved into a deployed application used by a community of subscribers to stay updated with my weekly content.

## Tech Stack
- Backend: Python (Flask)
- Frontend: HTML5, CSS3, JavaScript, Jinja2 Templates
- Styling: Bootstrap 5.2.2 for layout, supplemented by over 600 lines of custom CSS between my admin and main pages (so some overlap).
- Database: SQLAlchemy (SQLite/PostgreSQL)
- Communication: smtplib (Python's SMTP library).
- Deployment: Hosted on PythonAnywhere with domain management via Hostinger.
- Features: Custom Admin Dashboard, SMTP Email Integration, File Handling

## Key Features
- Custom Admin Dashboard: Instead of using a pre-built admin panel, I built one from scratch to manage blog posts, image galleries and audio files.
- Subscriber Notification System: I used an automated email system that notified users whenever new content (blogs, images or sermons) was published.
- User Engagement: A dedicated contact and feedback system allowing users to ask questions and interact directly with me (the author of the blog).

## What I Learned
- Flask fundamentals (models, views, templates)
- Database integration
- Deployment Process: I successfully deployed this application to a live environment and managed a real-time database of subscribers.

## Status
I decided to take down this site because I was uploading sermons to 2 sites (Sacramento Church Website - of which I was the pastor). The code is no longer actively maintained, but serves as my foundational learning project.
