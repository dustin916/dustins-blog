# Dustins Blog

A Flask-based blog application built as my first full-stack project.

## Features
- User authentication
- Create, edit, and delete posts
- Basic styling with HTML/CSS

## What I Learned
- Flask fundamentals (models, views, templates)
- Database integration
- Deployment process

## Status
No longer actively maintained, but serves as a foundational learning project.
